📖 Google Fit Setup Guide
✅ What Google Fit will auto-sync:
Daily steps · Heart rate · Sleep duration · Calories burned · Active minutes · Weight (if logged in Fit)
Steps to enable (once you deploy on Railway):
1
Go to Google Cloud Console
Visit console.cloud.google.com → Create a new project called "Life OS"
2
Enable the Fitness API
APIs & Services → Library → Search "Fitness API" → Enable
3
Create OAuth 2.0 Credentials
APIs & Services → Credentials → Create → OAuth Client ID → Web Application. Add your Railway URL as Authorized Origin.
4
Add Client ID to Railway Env Variables
In Railway → Your project → Variables → Add GOOGLE_CLIENT_ID=your_client_id. The Client Secret stays server-side only.
5
Click "Connect Google Fit" in the app
Once deployed, the Connect button activates and walks you through authorization for rvi2785@gmail.com
🔒 Security: Your Google credentials are never stored in the app or on GitHub. The OAuth Client Secret lives only in Railway's encrypted environment variables.
